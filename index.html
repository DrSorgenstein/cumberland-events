Have something happening?

Share a public event in Cumberland County. Follow these steps to add yours:

  1. Create or sign in to a free GitHub account. GitHub requires an account to submit an event. Browsing events and downloading calendar files do not require one.
  2. Fill out the event form. Include the title, date and time, public location, description, and a public information link.
  3. Wait for review. A site maintainer checks each submission before publishing it for everyone to see.
